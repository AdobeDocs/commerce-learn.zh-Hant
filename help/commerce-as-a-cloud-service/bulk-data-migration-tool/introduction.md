# 大量資料移轉工具簡介

準備Docker並存取大量資料移轉工具以將Adobe Commerce資料移轉到[!DNL Adobe Commerce as a Cloud Service] ([!DNL ACCS])。

## 這部影片是給誰看的？

* 解決方案架構師
* DevOps工程師
* 後端開發人員

## 視訊內容

* 瞭解大量資料移轉工具的功能和限制。
* 啟動之前，請確認Docker已安裝，且Docker引擎正在運行。
* 解壓縮工具套件並設定正確的檔案夾許可權。
* 檢閱此系列後續影片中設定的`.env.example`檔案。
