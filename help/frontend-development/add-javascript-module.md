# 新增JavaScript模組

{{only-for-on-prem-commerce-cloud}}

瞭解如何開發簡單的JavaScript模組，在店面顯示問候語「Hello World」。

## 這部影片是給誰看的？

* 開發人員

## 步驟

1. 建立模組。
2. 新增`requirejs-config.js`和JavaScript模組檔案。
3. 建立載入模組範本的版面配置更新。
4. 建立範本檔案。
5. 註冊模組並在店面進行測試。

## 視訊內容

* 設定模組和RequireJS設定。
* 透過版面更新和範本連線指令碼。
* 驗證頁面上的問候語。
