# 瀏覽商店設定和系統功能表

探索Adobe Commerce管理工作區，從篩選產品屬性到自訂產品網格及儲存檢視。 此影片也會介紹[!UICONTROL Stores]功能表，以及一般商店資訊、目錄設定、安全性、客戶和銷售的設定區域。

## 這部影片是給誰看的？

* 管理Adobe Commerce商店的管理員和使用者
* 開發人員熟悉Adobe Commerce管理員

## 視訊內容

* 依屬性範圍篩選固定的產品屬性網格。
* 顯示或隱藏欄，並將欄拖曳到不同的順序中，以自訂產品格線。
* 依顏色篩選產品，並將篩選的格線儲存為可重複使用的檢視。
* 在預設檢視和儲存的檢視之間切換，並更新現有的檢視。
* 瀏覽至商店設定，並探索一般、目錄、安全性、客戶和銷售設定。

>[!VIDEO](https://video.tv.adobe.com/v/3473115?learn=on)

## 儲存的格點檢視

已儲存的檢視會保留格點設定以供重複使用。 在視訊的藍色產品範例中，新新增的產品會在符合篩選器時顯示。 產品的顏色不再相符時即停止出現。

## 存放區設定

[!UICONTROL Stores]功能表提供存取存放區設定的許可權。 設定導覽會強調商店位置和電子郵件地址、貨幣、目錄顯示設定、安全性選項、客戶預設值、送貨方法和付款方法。
