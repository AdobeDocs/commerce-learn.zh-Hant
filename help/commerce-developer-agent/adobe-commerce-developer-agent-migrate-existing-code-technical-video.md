# Adobe Commerce Developer Agent移轉現有程式碼

並非每個專案都從空白設定開始。 此範例會使用移轉評估工具將現有的擴充功能移轉到App Builder，從PaaS平台移轉到Adobe Commerce as a Cloud Service，進而傳送給開發人員代理程式。

## 這部影片是給誰看的？

* Commerce開發人員
* 解決方案架構師
* 後端工程師

## 視訊內容

* 使用移轉評估工具掃描現有Commerce執行個體 — 複雜性評等、每個模組影響、風險訊號，以及重建、重新調整、取代或移除建議
* 檢閱高影響力模組的評估，包括其鉤點、檔案和簡單語言用途的摘要，該摘要可加倍作為現成的提示
* 直接將評估傳送至Developer Agent，無需手動複製
* 若要將焦點放在特定功能上，請回答代理程式的範圍設定問題
* 使用架構圖產生同步Webhook的藍圖，以取代風險最高的舊式邏輯
* 使用與每個處理常式一併撰寫的相符測試檔案來建置實作
