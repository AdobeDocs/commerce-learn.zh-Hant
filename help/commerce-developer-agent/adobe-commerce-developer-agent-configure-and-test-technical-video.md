# Adobe Commerce Developer Agent設定和測試

應用程式安裝後，其限制和訊息就會變成任何人都可以調整的業務設定 — 不需要程式碼。 此階段會設定購物車數量限制，並在店面測試其是否上線，以確認規則是否有效。

## 這部影片是給誰看的？

* Commerce開發人員
* Commerce管理員
* 銷售商

## 視訊內容

* 檢閱代理程式公開的業務設定 — 購物車數量上限和向購物者顯示的訊息
* 將每個SKU的最大購物車單位從預設值降低到較低值，並在沒有程式碼變更的情況下進行儲存
* 在店面新增產品並超過設定的限制
* 確認區塊和確切的錯誤訊息，強制執行即時，無需重新部署
