# Adobe Commerce Developer Agent概觀

Adobe Commerce Developer Agent將純英文請求轉換為運作中、已部署的商店功能 — 沒有手寫程式碼。 此概觀會依照完整歷程（從單一輸入的指示到實際店面的即時測試），並說明其為何會變更自訂Commerce功能的建置方式。

## 這部影片是給誰看的？

* Commerce開發人員
* 解決方案架構師
* 開發領導者

## 視訊內容

* 為什麼自訂Commerce功能傳統上需要手寫的webhook程式碼、App Builder設定和完整的建置 — 測試 — 部署週期
* 開發人員代理程式如何透過純英文規則處理技術實作（正確的webhook方法、裝載對應和設定架構）
* 自動程式碼驗證，可在使用者開啟偵錯工具之前擷取並修正建置錯誤
* 將限制和訊息公開為可在啟動後供商店團隊調整的業務設定
* 完整逐步解說的預覽：藍圖、開發、連線、部署、配置和測試
