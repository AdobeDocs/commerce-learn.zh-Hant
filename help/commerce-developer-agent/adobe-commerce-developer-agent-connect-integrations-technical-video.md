# Adobe Commerce Developer Agent連線整合

產生的程式碼需要執行位置，並且需要與存放區建立連線。 此階段整合了所有功能 — 在App Builder中託管程式碼、將其連線至您的Adobe Commerce執行個體，以及連結GitHub存放庫 — 之後才啟用該功能。

## 這部影片是給誰看的？

* Commerce開發人員
* 解決方案架構師
* 後端工程師

## 視訊內容

* 建立App Builder專案和工作區，以主控開發人員代理程式建立的程式碼
* 觀看代理程式支架專案和顯示未完成的設定專案
* 在開發人員控制檯中新增必要的Adobe Commerce as a Cloud Service API認證
* 將程式碼連線至特定的Adobe Commerce Cloud Service例項
* 若要儲存程式碼並進行版本設定，請連結GitHub存放庫
