# Adobe Commerce Developer Agent部署、關聯、安裝

應用程式已全面連線，可投入生產。 此階段會部署程式碼，然後將其關聯並安裝在Adobe Commerce管理員中，因此商店中會啟用新功能。

## 這部影片是給誰看的？

* Commerce開發人員
* 解決方案架構師
* Commerce管理員

## 視訊內容

* 要求開發人員代理程式從聊天室部署，並確認確切的組織、專案和工作區
* 預先部署驗證階段，然後在部署程式碼時串流建置和發佈輸出
* 從Commerce管理員的「應用程式管理」畫面，將已部署的應用程式關聯至特定商店
* 檢閱應用程式卡片 — 名稱、版本及其新增的功能(webhook)
* 安裝應用程式以啟動功能，並確認已成功安裝
