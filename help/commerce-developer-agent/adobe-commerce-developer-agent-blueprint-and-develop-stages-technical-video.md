# Adobe Commerce Developer Agent藍圖及開發階段

Blueprint和開發階段是簡單英文規則成為功能性、驗證程式碼的地方。 Adobe Commerce Developer Agent以購物車數量限製為例，將所述的規則轉換為您可以檢閱的正式計畫，然後在即時工作區中寫入並自我驗證webhook程式碼。

## 這部影片是給誰看的？

* Commerce開發人員
* 解決方案架構師
* 後端工程師

## 視訊內容

* 以淺顯語言說明商業規則（購物車數量限制）並產生App Builder模式的Blueprint
* 檢視Blueprint和計畫面板 — 執行階段選擇、企業整備檢查清單和信賴度估計
* 計劃分成具體任務，再加上webhook如何評估並封鎖購物車新增的邏輯圖
* 開發階段會將程式碼寫入專案工作區中，且檔案和程式碼會串流至「專案總管」
* 自動建置、測試和自我校正，以及代理程式暫停詢問何時需要釐清
* 驗證產生的設定、商業設定結構描述和webhook詳細資訊
